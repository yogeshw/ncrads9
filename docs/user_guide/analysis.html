Analysis Tools

The Analysis menu is for measuring and for looking closely. Most of these tools act on the current frame and the plane you are looking at.

Looking at values

  • Pixel Table — the values around the cursor as a grid, updating as you move, at 3×3, 5×5, 7×7 or 9×9. This is the tool for deciding whether a feature is one hot pixel or several.
  • Statistics — sum, mean, median, standard deviation, minimum and maximum. Over a region if one is selected.
  • Histogram — the distribution of the valid pixels, with NaN and infinity excluded and a summary of min, max, mean and median.
  • Radial Profile — mean value against radius from a chosen centre, for checking a PSF or the falloff of a source.
  • Name Resolution — look up a source name with SIMBAD or NED.

View → Horizontal Graph and Vertical Graph add live cuts along the row and column under the cursor, beside the image. Analysis → Graph Parameters sets their scale, including a log axis.

Contours

Analysis → Contours draws them; Contour Parameters chooses how many, between which limits, by which spacing (linear, logarithmic, square root, or levels you type), and their colour, width and dash. Two methods are offered, as in DS9:

  • Block averages the image down before tracing, so a larger smoothness is faster and coarser.
  • Smooth smooths the image before tracing, so a larger smoothness is slower and rounder.

Contours can be saved and loaded as DS9 contour files, and copied and pasted between frames.

Sigma levels. The parameters dialog can set levels as multiples of the noise above a base, which is the usual way to contour a radio map. Give it the RMS from an empty part of the field.

Coordinate grid

Coordinate Grid and its parameters draw a graticule from the WCS — see Coordinates and WCS.

Block and smooth

  • Block averages neighbouring pixels together, by a factor from 1 to 256, or Block In / Out / Fit. It changes what the analysis tools see, not only the picture.
  • Smooth convolves the image. Four kernels: boxcar, tophat, Gaussian, and an elliptical Gaussian that takes a major and minor radius and a position angle. Also seen by the analysis tools.
Both change the values the other tools measure. Statistics taken on a smoothed image are statistics of the smoothed image, and its noise is correlated. Turn them off before measuring.

Masks

Mask Parameters overlays a second image as a mask — a colour, a transparency, and the range of mask values to paint — for showing a segmentation map or a flag array on top of the data.

Catalogues and image servers

  • Catalogs queries SIMBAD, NED, Vizier and others for a field and overlays the sources it finds. Catalog Tool is the table itself — sort it, filter it, and select a row to find that object on the image.
  • Image Servers fetches a cutout from DSS, 2MASS, SDSS and others.
  • Footprint Servers overlays the coverage of an observatory's archive.
  • Virtual Observatory queries VO services; Archives opens the archive web pages directly.

Plot Tool

Plot Tool opens a plotting window of its own, which is where cuts, profiles and region plots land. It has menus for loading and saving the data, for the axes, for the legend, and for the style of each dataset, and it can write the plot out as an image.

Analysis command files

Load Analysis Commands reads a DS9 analysis file (.ans), which adds your own entries to the bottom of the Analysis menu, each running an external program on the current file. This is how an observatory ships its own reduction tools inside the viewer. Analysis Command Log shows what has been run; Clear Analysis Commands removes them.

NCRADS9 loads ds9.ans and *.ds9 from the usual places at startup, as DS9 does. Preferences → Startup turns that off.
