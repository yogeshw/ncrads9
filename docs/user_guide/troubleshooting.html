Troubleshooting

The image is black, or almost

Almost always the scale. The default limits are the data's own minimum and maximum, and one hot pixel is enough to flatten everything else. Try Scale → ZScale, then Scale → Log. Scale → Scale Parameters shows the histogram with the limits marked, which usually makes the reason obvious.

If the image is black even after that, and you are using the GPU renderer, turn it off in Preferences → General — some drivers hand back an empty frame.

The colours went wrong after I dragged

Right-drag adjusts contrast and bias. Color → Reset Contrast/Bias puts them back without changing your colour table.

The image looks upside down

It probably is not. FITS counts rows from the bottom and screens count from the top, so an image with no WCS can look flipped compared with another program's default. Zoom → Invert Y settles it either way, and the coordinate readout is the thing to trust. With a WCS, Zoom → Align puts north up.

Dragging pans when I want to draw a region

The left button follows Edit. Set Edit → Region.

A window is in the way and will not move

Every window here can be dragged by its title bar and pushed behind the main one, detached menus included. If one genuinely cannot be, that is a bug worth reporting.

Everything is grey and hard to read

Preferences chooses the theme. System follows the desktop's own colours, including a dark mode set outside NCRADS9.

My contours join two separate sources

At a low enough level two nearby sources genuinely merge, and one contour around both is correct. If they are clearly separate and a straight line runs between them, that is not — report it.

Statistics disagree with another tool

Check three things: whether Block or Smooth is on, since both change the values the tools measure; whether the region is in the coordinate system you think; and whether the other tool includes or excludes the boundary pixels of an aperture.

Positions disagree with a catalogue

Check that both are in the same sky system. ICRS and FK5 differ by tens of milliarcseconds, FK4 by arcminutes. The WCS menu sets which one NCRADS9 is reporting.

A script that drives DS9 does not drive NCRADS9

Point it at ncrads9 rather than ds9. If a particular access point is refused, the reply says so; Help → Reference Manual lists every name this program answers. Tcl scripts do not run here — the console is Python — but their XPA commands do.

It will not start, or a menu entry does nothing

Run it from a terminal and read what it prints, and check the status bar at the bottom of the window, which is where failures are reported. Then see Help → Help Desk for what to include in a report.
