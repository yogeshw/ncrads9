Regions

A region marks part of an image: an aperture to measure, a source to label, an artefact to exclude. Regions are drawn over the pixels, saved as text, and understood by other astronomical software.

Drawing one

  1. Edit → Region puts the left mouse button into drawing mode. (Under Edit → None, dragging pans instead.)
  2. Region → Shape chooses what a drag draws.
  3. Drag on the image. Polygons and segments take a click per vertex and a right-click to finish.

Editing

Click a region to select it and drag to move it; drag a handle to resize. Double-click opens its dialog, which is where you type exact centres, radii and angles, set the text label, and reach that region's own analysis. Region → Get Information does the same for the selection.

All, None and Invert change the selection; Front, Back, Move to Front and Move to Back change the stacking order of overlapping regions.

Colour, width, font and properties

The Color, Width and Font cascades apply to the selected regions, or set the default for the next one when nothing is selected. Properties holds the flags:

PropertyMeaning
Fixed in SizeKeeps its screen size when you zoom, instead of scaling with the image.
Can Edit / Move / Rotate / DeletePermissions. Turn off Can Delete to protect a region from Delete All.
Include / ExcludeWhether the region adds to the area of interest or cuts out of it. An excluded region is written with a leading - and is how you mask a star out of an aperture.
Source / BackgroundWhat the region is for. Analysis tools that subtract a background use this.
Dash, FillAppearance. These two are ours; DS9 has no counterpart.

Groups, composites and templates

  • New Group names the current selection so it can be recalled; Groups lists and manages them.
  • Composite Region → Create welds a selection into one region that moves as a unit; Dissolve takes it apart again.
  • Template → Save writes the regions relative to a reference point rather than at absolute coordinates, so Open can drop the same arrangement onto another image — a slit pattern, or a set of apertures.
  • Instrument FOV drops the footprint of a real instrument on the image: Chandra ACIS and HRC, XMM EPIC, and the MMT and Suzaku instruments.

Files

Region → Save writes DS9 format (.reg), which CASA, topcat, pyregion, the regions astropy package and DS9 itself all read. List shows the same text in a window without writing it, which is the quickest way to check exactly what you have.

Open adds the file's regions to what is already there. Delete All and Open replaces them. This is DS9's behaviour and the reason it has both entries.

Save Selection, List Selection and Delete Selection do the same for the selected regions only.

Measuring with a region

A region's own dialog reaches its statistics, its radial profile, its histogram and a plot along it. Region → Centroid snaps regions onto the source they sit near, and Region Parameters → Auto Centroid does that as each one is drawn. The same dialog's Auto Plot 2D, Auto Plot 3D and Auto Plot Statistics open the corresponding window automatically for every new region.

Region Parameters → Show and Show Text hide the overlay and its labels without deleting anything — useful just before saving a figure.
