Getting Started

NCRADS9 displays FITS images. This page gets you from an empty window to a picture you can read, and names the parts of the interface the rest of the guide refers to.

Installing

From the Python Package Index:

pip install ncrads9

Or from a checkout, which is what you want if you intend to change it:

git clone https://github.com/yogeshw/ncrads9.git
cd ncrads9
pip install -e .

NCRADS9 needs Python 3.10 or later. pip pulls in PyQt6, astropy, astroquery, numpy, scipy, scikit-image, pillow and requests.

A note on scikit-image. It is the contour tracer. NCRADS9 has one of its own and will fall back to it, so contours work either way, but the bundled tracer is slower on large images.

Starting it

ncrads9                  # empty, ready to open something
ncrads9 image.fits       # straight into a file
ncrads9 -log -heat image.fits            # with a scale and a colour table
ncrads9 -rgb -red r.fits -green g.fits -blue b.fits

The command line takes DS9's startup options, so a script that launched DS9 will usually launch this. ncrads9 --help prints a summary; ncrads9 --help-html opens the full list in a browser. The Quick Reference has the common ones.

The window

PartWhat it is
Menu barEverything the program does. Each menu has a dashed line across the top: click it to tear the menu off into a window of its own that stays open.
Button barUnder the menus, in categories (File, Edit, Frame, Bin, Zoom, Scale, Color, Region, WCS, Analysis, Help). The buttons mirror the menu entries, so a button does exactly what the menu entry of the same name does.
Information panelFilename, object, and the value and coordinates of the pixel under the cursor, in image, physical and world coordinates.
PannerThe whole image with a box showing which part you are looking at, and a compass for north and east.
MagnifierThe pixels immediately under the cursor, enlarged.
Colour barThe colour table in force, with the data values it maps.
Main displayThe image.
Status barWhat just happened, and what went wrong when something did.

View turns each of these on and off, and chooses a horizontal or vertical layout. View → Basic and Advanced switch between a spare layout and everything at once.

The mouse

GestureEffect
Left dragDepends on the mode set in Edit. With Edit → None it pans; with Edit → Region it draws the shape chosen in Region → Shape.
Right dragContrast and bias. Left and right slides the midpoint of the colour table, up and down steepens or flattens it. This changes only the display, never the data.
Middle clickCentre the image on the point clicked.
Scroll wheelZoom in and out about the cursor.
Double click a regionOpen its dialog, to type exact coordinates and sizes.
Dragged the right button and lost the picture? Color → Reset Colormap puts the contrast and bias back.

A first look at an image

  1. File → Open, and pick a FITS file. If it has more than one displayable extension you are asked which; DS9 takes the first without asking, and Preferences → General restores that behaviour if you prefer it.
  2. The image arrives scaled linearly between its own minimum and maximum, which for most astronomical data shows almost nothing: one bright star sets the maximum and everything else is black.
  3. Scale → ZScale. This is the usual first move — it picks limits from the middle of the distribution and ignores the extremes.
  4. Scale → Log if the source has a large dynamic range.
  5. Color → Heat, or whichever table suits. Right-drag to fine-tune.
  6. Zoom → Zoom Fit to see all of it, then scroll to go in.

That is the whole loop for looking at one image. The rest of this guide is about measuring what you find, comparing frames, and getting the result back out.
