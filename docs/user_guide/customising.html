Customising NCRADS9

Edit → Preferences (Ctrl+,) is a list of topics down the side and a page of settings for each. The topics are DS9's, in DS9's order, so a setting is where you expect it to be. Changes apply at once and are written to a preferences file in your home directory.

The topics

TopicHolds
GeneralAutoloading FITS regions, confirmation dialogs, whether to ask which extension to load, auto recovery and its interval, the GPU renderer and its tile and cache sizes, worker threads, anti-aliasing.
PrecisionHow many digits coordinates and values are shown to.
StartupWhat is on screen when the program opens, and whether analysis command files are read.
Menus and ButtonsThe button bar, the icon bar, and detachable menus.
Panner, MagnifierThe compasses, the magnifier's zoom and cursor.
3D, Bin, Zoom, Scale, Color, Region, Contour, Grid Defaults for each of those, applied to the next thing you create.
CoordinatesThe sky frame and format the readout starts in.
ExamineWhat the Examine pointer mode does.
HTTPProxy host and port, timeout, user agent — for the catalogue and image servers behind a firewall.

Themes

System follows your desktop's own colours, including a dark mode set outside NCRADS9. Light and Dark impose one regardless. Every window follows the choice, dialogs and help pages included.

Detachable menus

Every menu and submenu has a dashed line across the top. Click it and the menu detaches into a window of its own that stays open, so a menu you are working through — Scale, Colormap, Region → Shape — can sit beside the image instead of being reopened for every change. A detached menu is an ordinary window: move it, and push it behind the main one when it is in the way. Close it and the menu goes back to normal.

Preferences → Menus and Buttons → Detachable menus turns the handles off.

Keyboard shortcuts

Every shortcut is a preference and can be rebound; Help → Keyboard Shortcuts lists the current set, and the Quick Reference has the defaults. A binding that collides with another is reported rather than silently taking precedence.

Language

The interface can be translated, and dialogs are translated as they are first shown.

The GPU renderer

NCRADS9 can draw the image through OpenGL, in tiles, which is faster on large images. There is a CPU path that produces the same picture, and Preferences → General → Use the GPU renderer chooses. Turn it off if your driver misbehaves — a black image where there should be data is the symptom. DS9 has no GPU backend; this is ours.
