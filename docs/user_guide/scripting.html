Scripting: XPA, SAMP and Python

NCRADS9 is meant to be driven from outside as well as clicked. There are three ways in, and they suit different jobs.

XPA

XPA is the interface most pipelines use. A running NCRADS9 answers the same access-point names DS9 does, so a script written for DS9 usually works if you point it at ncrads9:

xpaset -p ncrads9 file image.fits
xpaset -p ncrads9 scale zscale
xpaset -p ncrads9 cmap heat
xpaset -p ncrads9 regions load sources.reg
xpaget ncrads9 crosshair wcs fk5
xpaset -p ncrads9 saveimage png figure.png

xpaset -p sets something, xpaget reads it back. Help → Reference Manual lists every name this program answers, generated from the table that implements them, so it cannot fall behind the code. A name that is not implemented answers with a message saying so rather than failing silently.

From Python, the pyds9 family of wrappers works, as does calling xpaset/xpaget through subprocess. File → XPA → Connect and Disconnect control whether the server is listening.

SAMP

SAMP is the Virtual Observatory's messaging protocol, and it is the right choice for talking to topcat, Aladin and other VO tools on the same desktop. File → SAMP → Connect joins a hub — SAMP Hub starts one if none is running — and then:

  • Image sends the current image to the other applications.
  • Table sends a table.
  • Information shows what else is connected.

Sources highlighted in topcat appear on the image, and vice versa.

The Python console

File → Open Python Console (Ctrl+`) gives you a Python prompt inside the running program, with the main window bound so you can reach the frames, the data and the controllers directly:

window.frame_manager.current_frame.image_data.shape
window.scale.set_scale("log")
window.analysis.set_contours(True)

Run Python Script executes a file in the same context. This is the quickest way to do something the menus do not, and the easiest way to break something: it is a real interpreter with real access.

NCRADS9 has a Python console where DS9 has a Tcl one, and Source TCL becomes Run Python Script. A Tcl script written for DS9 will not run here; its XPA commands will.

Analysis command files

For running an external program on the current file, a DS9 analysis file adds entries to the Analysis menu — see Analysis Tools.

The command line

Everything at startup can be set from the command line in DS9's syntax — see the Quick Reference.
