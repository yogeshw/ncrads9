Scaling the Data

A FITS image holds numbers; a screen shows 256 greys. The scale is how the one becomes the other, and it is the single setting that most decides whether you can see what is in your data. Nothing here changes the pixel values — only how they are drawn.

Two choices make up a scale: which range of values to spread across the display (the limits), and what curve to spread them along (the algorithm).

Limits

The top of the Scale menu's second group:

LimitsWhat they areWhen to use them
Min MaxThe smallest and largest pixel in the image.Rarely useful on real data: one hot pixel or one bright star sets the maximum and flattens everything else. Guaranteed to show every value, which is its one virtue.
ZScaleIRAF's algorithm: it samples the image, fits the middle of the value distribution and ignores the tails. The default, and the usual first move. Shows faint structure without the bright sources taking over.
ZMaxZScale's lower limit with the true maximum above it.When you want the faint end zscaled but the peak value still on the bar.
99.5% down to 90%Clip that percentage of the distribution, discarding the rest at both ends. A blunter, more predictable alternative to zscale.
UserThe pair you last typed.Comparing several images on identical limits.
OtherType a pair now.As above.

Scale → Scale Parameters shows the histogram with the current limits drawn on it, which is the quickest way to understand why an image looks the way it does. ZScale Parameters exposes zscale's contrast, sample size and line count if the defaults are not suiting your data.

Where the limits are measured

  • Global / Local — compute limits over the whole image, or only over the part currently displayed. Local re-stretches as you pan, which is excellent for exploring and misleading for comparing.
  • Min Max mode and Use DATASEC — whether to respect the header's DATASEC and ignore overscan regions when measuring.

Algorithms

AlgorithmShapeGood for
LinearStraight.Flat fields, anything whose values span a small range.
LogCompresses the bright end hard. Large dynamic range: a galaxy core and its outskirts at once. The Log Exponent entry sets how hard.
Square RootMild compression.A gentler log; often the best-looking choice for broadband images.
SquaredExpands the bright end.Separating values near the top of the range.
PowerAdjustable exponent.When square root and squared bracket what you want.
ASINH, SINHLinear near zero, logarithmic further out.Faint emission on a noisy background — asinh does not blow up at or below zero the way log does, which matters in interferometric maps with negative pixels.
Histogram EqualizationEvery displayed grey gets the same number of pixels.Finding structure. Not for figures: it makes the brightness scale meaningless.

Contrast and bias

Right-drag on the image slides the colour table's midpoint (left and right) and steepens or flattens it (up and down). This sits on top of the scale, and is the fastest way to explore a stretch you have already chosen. Color → Reset Colormap undoes it. To set exact numbers, use Color → Colormap Parameters.

Comparing frames? Set the limits by hand or use Frame → Lock → Scale Limits, so that a difference on screen is a difference in the data rather than in the stretch.
