Saving, Exporting and Printing

There are four different things you might mean by "save", and NCRADS9 keeps them apart. Choosing the wrong one is the commonest way to end up with a file that is not what you wanted.

You wantUseYou get
The data, as FITSFile → Save / Save AsA FITS file of the current frame.
The data, in another formatFile → Export Array, NRRD, ENVI, GIF, TIFF, JPEG or PNG of the pixels.
The picture, as it looksFile → Save Image FITS, EPS, GIF, TIFF, JPEG or PNG of the view — at the zoom you are at, with the regions, contours and grid on it.
Everything, to come back toFile → Backup The whole session: every frame, its settings, its regions.

Save and Save As

These write what is displayed, not the array as it came off disk. If you have blocked, smoothed, or are looking at one slice of a cube, that is what lands in the file — with the header's axis cards corrected to match and an NCSPEC card recording the specification it was loaded from. This is a deliberate divergence from a viewer that always writes the original; it means the file matches the picture you were working with.

Save as offers the same set of forms as Open as: a slice, an RGB/HSV/HLS image or cube, a multiple-extension cube, or a mosaic.

Save Image

This is the one for a figure or a talk. It captures the view as rendered: the current zoom and pan and rotation, and every overlay — regions, contours, the coordinate grid, catalogue symbols, illustrations. What you see is what is written.

Hide what you do not want first — Region → Region Parameters → Show and the corresponding switches for the grid and contours — rather than deleting it.

Printing

File → Print (Ctrl+P) sends the same view to a printer or to a PostScript file. Page Setup (Ctrl+Shift+P) sets orientation, paper size and scale beforehand.

Backup and Restore

Backup writes the session — frames, their files, their scales and colour tables, their pan and zoom, their regions, the contour and grid settings, the colour tags — and Restore reads it back. Use it to park an analysis overnight, or to hand a colleague exactly what you are looking at. The format is DS9's.

NCRADS9 also autosaves a recovery snapshot; Preferences → General sets the interval or turns it off.

Movies

File → Create Movie records a cube stepping through its planes, or frames blinking, to a video file — for a talk, or for showing a time series.

Notes

File → Notes (Ctrl+Shift+N) is a scratchpad that travels with the session, so the reason you were looking at something is still there when you restore it.
