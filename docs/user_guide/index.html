NCRADS9 User Guide

NCRADS9 is a FITS image viewer written in Python and Qt6 at the National Centre for Radio Astrophysics. This guide covers looking at an image, measuring what is in it, comparing several, and getting the result back out.

If you have used SAOImageDS9, you already know most of this: the interface is modelled on DS9's, and the region files, session files and XPA names are DS9's so the two interoperate. Where NCRADS9 does something differently the page says so. The ideas underneath — colour tables, blink comparison, contour and grid overlays, regions over the pixels — are older than DS9 and belong to a longer line of astronomical software; Help → Story of SAOImageDS9 in the program says where they came from.

In a hurry? Read Getting Started, then Scaling the Data. Those two cover most of what people need on the first day.

Contents

  1. Getting Started
    Installing, starting, the parts of the window, the mouse, and a first look at an image.
  2. Opening Files
    FITS and the other formats, Open as, extensions, event tables and binning, images from the network.
  3. Scaling the Data
    Limits and algorithms — the setting that most decides whether you can see what is in your data.
  4. Colour
    Colour tables, inverting, the colour bar, colour tags, and which tables are safe for publication.
  5. Coordinates and WCS
    Image, physical, amplifier, detector and world coordinates; sky systems; the grid; pan, zoom and rotate.
  6. Frames and Comparison
    Several images at once: tile, blink and fade; match and lock; RGB composites; cubes and 3D.
  7. Regions
    Drawing, editing, properties, groups and templates, the DS9 region format, and measuring with a region.
  8. Analysis Tools
    Pixel table, statistics, histogram, radial profile, contours, block and smooth, catalogues and the plot tool.
  9. Saving, Exporting and Printing
    The four different things “save” can mean, and which one you want.
  10. Scripting: XPA, SAMP and Python
    Driving NCRADS9 from a pipeline, from other VO tools, or from a prompt inside the program.
  11. Customising NCRADS9
    Preferences, themes, detachable menus, keyboard shortcuts, the GPU renderer.
  12. Quick Reference
    Keyboard, mouse, pointer modes, command-line options, and the formats read and written.
  13. Troubleshooting
    The image is black, the colours went wrong, positions disagree — and what to do about each.

Help inside the program

The Help menu carries the same material and a little more: a User Manual, an FAQ, a Reference Manual listing every XPA access point (generated from the code, so it cannot go stale), Release Notes, a Help Desk page saying how to report a problem, and Keyboard Shortcuts.

Reporting a problem

github.com/yogeshw/ncrads9/issues. Include the version from Help → About NCRADS9, your operating system, what you did and what happened instead.
